
# ICS Editor — 截图 / 文字 → 带提醒的 .ics 日历

> **ICS 不是规划工具，是触发工具。**
> 让截图和文字，15 秒变成手机日历里响起的提醒。

---

## ✨ 核心特性

- 🏠 **模板分类导航**：导航页按「学习 / 健康 / 工作 / 生活 / 家庭」分类浏览精选模板，一键带模板进编辑器；🔍 ICS 全网垂直搜索（`filetype:ics`）正在开发中。
- 📸 **截图 AI 识别**：上传赛程/课表截图 → 浏览器直连 DeepSeek Vision 提取事件 → 一键导出 ICS（首次用点页面「⚙️ API Key 设置」，粘贴自己申请的 Key；Key 只存本浏览器、图片只发给 DeepSeek）。
- 📝 **智能文字解析**：粘贴一段文字（如"周一 8 点开会，提前半小时提醒"），自动解析时间、地点、提醒。
- ⏰ **默认 15 分钟前提醒**：每个事件自动带上 `VALARM`，解决厂商日历"节日/订阅默认不提醒"的痛点。
- 🌍 **长尾日历覆盖**：体育赛事、课程表、宗教节日、读书计划……任何非标准日历需求。
- 🔒 **纯前端 + 隐私优先**：100% 浏览器本地运行，数据不出本机。
- 🆓 **开源免费**：MIT License。

## 🎯 为什么做这个？

大厂做"标准化日历数据"（中国节假日、全球主流节日、农历节气），但：

- 体育赛事（F1、英超、世界杯）的赛程提醒？没有。
- 开学季课程表导入日历？没有。
- 宗教节日（伊斯兰历、印度历、希伯来历）的提醒？没有。
- 厂商日历对节日、订阅日历**默认不提醒**——因为客户端会忽略订阅源的 VALARM，且厂商出于防打扰考虑默认关闭。

**ICS Editor 反其道而行**：生成 ICS 时强制带上 `VALARM`，并引导用户如何在 iOS/Android/Google 日历上开启提醒。

## 📖 新手指南

👉 **[ICS 是个啥？—— 为什么它是日历界的通用文件](guide.html)**

30 秒看懂：ICS 是 IETF 制定的开放标准（RFC 5545），Google 日历、苹果日历、Outlook 全平台通用。一次生成，处处可用。

## 🛠️ 技术栈

- 前端：纯 HTML + CSS + JavaScript，可整站静态托管（Cloudflare Pages / GitHub Pages 均可）
- AI 识别：DeepSeek Vision（`deepseek-v4-flash-vision-exp`），浏览器直连、用户自备 API Key（页面内有大白话申请教程）
- 可选后端：`server.js` 本地 Node 代理（浏览器被拦截、或不想在页面填 Key 的团队场景）
- 无数据库、无追踪
