🧐 什么是 .ics 文件？

.ics 就像日历界的 PDF——不管你用苹果、安卓还是电脑，只要导入这个文件，就能把日程/课表加进自带的日历 App 里。它是全球通用的日历格式标准。

📱 各平台导入教程

📱 iPhone / iPad

  1. 把 .ics 文件保存到"文件"App（微信/QQ 里长按文件 → 存储到文件）
  2. 打开"文件"App → 找到 .ics 文件 → 点击
  3. 点「添加到日历」→ 选择添加到哪个日历 → 完成
  4. 打开"日历"App 就能看到

🤖 Android

  1. 下载/保存 .ics 文件到手机
  2. 打开 Google 日历 App → 左上角 ☰ → 设置 → 导入
  3. 选择 .ics 文件 → 选择要添加的日历账户 → 导入
  4. 国产手机（华为/小米等）：用"日历"App → 设置 → 导入日程

🍎 Mac

最简单：双击 .ics 文件 → 自动弹出"日历"App → 点「导入」即可。

💻 Windows / Outlook

双击 .ics 文件（默认用 Outlook 打开）→ 点「保存并关闭」；或打开 Outlook → 文件 → 打开和导出 → 导入。

🌐 Google 日历（网页版）

  1. 电脑浏览器打开 calendar.google.com
  2. 右上角 ⚙ 设置 → 导入和导出
  3. 选择 .ics 文件 → 导入

⚠️ 注意：Google 日历手机 App 不支持导入 .ics，必须用网页版。

❓ 常见问题

导入后日历里看不到？
检查是否添加到了正确的日历账户（iCloud / Google / 本地）。iPhone 用户确认"日历"App 中对应账户已勾选显示。
时间不对？
检查手机时区设置。ICS 文件使用 UTC 时间，导入时会自动转为本地时区。
重复规则（每周/单双周）没生效？
部分安卓自带日历对复杂重复规则支持不佳，建议使用 Google 日历或 Outlook。
怎么删除导入的课表？
iPhone：日历 App → 找到导入的事件 → 编辑 → 滚动到底部「删除此事件」。批量删除：在日历设置中找到导入时使用的日历账户，直接删除该日历。

💡 小贴士

每年 2 月和 9 月是导入课表的高峰期。导入后建议先在日历里翻到第一周确认一下，确保没有识别错误。本工具纯前端运行，你的数据不会上传到任何服务器。
